# Bramasetio Portfolio

Welcome to the source code for my personal portfolio website! This project is designed to showcase my skills, projects, and experiences as a Game Developer Student.

## 🚀 Features

- **Futuristic UI/UX**: Designed with a cyberpunk-inspired dark theme, neon accents, and glassmorphism.
- **Interactive Custom Cursor**: A glowing custom cursor that reacts to interactive elements.
- **Boot Sequence Intro**: A terminal-style booting animation when the page loads.
- **3D Holographic Elements**: CSS-animated 3D objects in the hero section.
- **3D Tilt Cards**: Portfolio project cards that react to mouse movement using `vanilla-tilt.js`.
- **Fully Responsive**: Optimized for both desktop and mobile devices.
- **Working Contact Form**: Integrated with Web3Forms to send emails directly to my inbox.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Custom variables, flexbox/grid layouts, keyframe animations, and 3D transforms.
- **JavaScript (Vanilla)**: DOM manipulation, custom cursor logic, scroll reveal, and typing animations.
- **Font Awesome**: Icons.
- **Google Fonts**: Space Grotesk & Inter.
- **Vanilla-Tilt.js**: 3D tilt effects for cards.

## 📧 Setting Up the Contact Form (Web3Forms)

The contact form is configured using [Web3Forms](https://web3forms.com/). To ensure emails are sent to your inbox:
1. Go to Web3Forms and get your free Access Key.
2. In `index.html`, locate the `<form>` inside the Contact section.
3. Replace the `value="YOUR_ACCESS_KEY_HERE"` inside the hidden input with your actual Access Key.
